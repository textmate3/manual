# Updating {#updating}

By default TextMate will prompt you when a new version is available.

The _Software Update_ page available via _TextMate → Preferences…_ (`⌘,`) allows you to change `Watch For` to _Nightly Builds_ which will increase the frequency, despite its name though, the there is no new build every night.

If you switch to _Nightly Builds_ and there is an issue with one of the builds, you can switch back to _Normal Releases_ and select `Check Now`, which then allows you to downgrade.

You can also find older builds in `~/Library/Caches/com.macromates.TextMate`.
