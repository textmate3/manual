# TextMate 2.1

The manual for TextMate 2.1, a continuation of the 2.0 version of the app.
2.1 is the first release of the TextMate 3 project.

This directory holds what is new or different in 2.1. For everything that did not change, the [2.0 manual](../2.0/) still describes the editor: how documents, projects, bundles, snippets, commands, scopes and grammars work is as it was.

| Page                                    | What it covers                                                                                       |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| [Requirements](requirements.md)         | The system and the hardware, and what the application installs for itself                            |
| [What is new](whats-new.md)             | The features and changes a person meets in 2.1                                                       |
| [Breaking changes](breaking-changes.md) | What 2.0 did that 2.1 does differently, and what to do about each                                    |
| [Runtimes](runtimes.md)                 | The Ruby and the Python that bundle commands run on, how they arrive, and how to see and change them |

The version is 2.1.0 and it has not been released. Alphas and betas exist for the people building it. The pages here describe the application as it stands on the main branch, so a detail may move before the release and this directory moves with it.
